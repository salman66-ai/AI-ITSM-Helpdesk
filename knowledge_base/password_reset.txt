Password Reset Guide

Title: Corporate Password Reset and Account Unlock

Issue:
Employees may be unable to access corporate applications when their
password has expired or their account is locked.

Troubleshooting Steps:

1. Confirm that the employee's password has expired.
2. Verify the employee identity according to the organization's
   authentication procedure.
3. Reset the expired password using the approved password reset system.
4. If the account is locked, unlock the account using the approved
   account management system.
5. Ask the employee to sign in again with the new password.
6. Validate that the employee can access the required application.

Automatable Actions:

- Reset expired password.
- Unlock user account.
- Validate account access.

Automation Safety:

Password reset and account unlock actions must be recorded in the
ITSM audit log.

Escalation:

If password reset or account unlock fails, create an IT incident
and escalate to the appropriate IT support team.

Category: Access Management
Sub-category: Password Reset
